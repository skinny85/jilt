# Contributing to Jilt

## Building locally

This library is a standard Java [Gradle](https://gradle.org) project,
so it should build (just invoke `./gradlew build`)
and work in your IDE without any special configuration.

In order for auto-completion to work correctly,
make sure to enable annotation processing in your IDE,
like it's explained in the [main ReadMe file](./Readme.md#working-in-an-ide).

## Submitting Pull Requests

This project uses the [OneFlow Git workflow](https://www.endoflineblog.com/oneflow-a-git-branching-model-and-workflow),
so make sure to open your Pull Requests against the `develop` branch,
and not `master`, which is the default branch for this repository.
